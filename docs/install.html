Canon EOS 6D · Firmware 1.1.6 Only

Install & Quick Start

Everything runs off the SD card — Canon's ROM is never modified. Remove the card and the camera boots factory firmware normally.

Before You Start

Requirements

Camera

Canon EOS 6D (FW 1.1.6)

Check Menu → Firmware Ver. on your 6D. It must be 1.1.6 — other versions will not boot this build.

Storage

SD / SDXC Card

Format the card in the camera first (FAT32 or exFAT). Keep a full battery while running the one-time bootflag step.

Package

Release Zip or Local Build

Download magiclantern.zip from GitHub Releases or build from source below.

Step by Step

Install on a new SD card

01

Format the SD card in the Canon 6D

Insert the SD card into the camera and run Menu → Format card (standard format is fine).

02

Copy files to the SD card root

Unzip magiclantern.zip and copy autoexec.bin, ML-SETUP.FIR, and the entire ML/ folder to the root of the card:

/Volumes/EOS_DIGITAL/
├── autoexec.bin
├── ML-SETUP.FIR
└── ML/
    ├── FILM/          # 46+ .fs film recipes
    ├── FILMS/         # Shelf XML catalogue
    ├── FILMSIM/       # Canister art (CANS.DAT)
    ├── modules/       # film_sim.mo + 6D_116.sym
    └── SETTINGS/      # film_sim.en
03

Enable BootDisk (one time per body)

Put the card back in the 6D, switch to M mode, open Menu → Firmware Ver. 1.1.6 → Update, and confirm running ML-SETUP.FIR. Wait for the green confirmation screen, then power cycle the camera.

04

Enable Film Sim in Magic Lantern

Press ERASE (Trash) to open the ML menu → Modules → ensure film_sim.mo is enabled (and film_lv.mo is disabled/removed so they do not conflict), then reboot once.

On The Camera

First-time shooting setup

1 · Pick a Stock

Film Dev → Film Shelf

Turn Film Sim → On, open Film Shelf, turn the main dial to browse 35 mm canisters, and press SET to apply. The 12×17×17 YUV lattice bakes automatically in ~150 ms.

2 · Add Colour to LiveView & XPan Bars

Film Dev → LiveView & Aspect

Enable LiveView → LiveView Filter to grade the live LCD feed in real time, and set Aspect → 65:24 XPan (or 2.39:1, 16:9, 1:1, 4:5) for matching LiveView framing bars and in-shutter JPEG crops.

3 · Shot Info Header & Paper Frame

Film Dev → Header

Enable Header to burn a white or dark gallery border with the film canister, camera body, lens, aperture, shutter speed, and ISO straight into the JPEG on the card.

4 · Custom Colour

Film Dev → Custom Look

Open Open Creator to tune all 12 colour wedges (Sat / Lum / Hue) and press Q for the 5-point Highlight/Shadow curve. Press PLAY to save to a slot.

Wireless Workflow

Import Lightroom .xmp presets over Wi-Fi

Convert any Lightroom / Camera Raw .xmp preset into a 48-sector .fs recipe and push it directly to your 6D over Canon's built-in Wi-Fi.

01

Enable Wi-Fi on the Canon 6D

On the camera: Menu → Wi-Fi → Enable → Wi-Fi function → EOS Utility (Connect to computer). Connect your computer and 6D to the same Wi-Fi network (or the camera's own AP).

02

Push a Lightroom .xmp or .fs recipe

tools/push_fs.py auto-discovers the 6D on PTP/IP port 15740, converts .xmp on the fly, writes ML/FILM/<CODE>.fs, registers it on the Film Shelf, and activates it live:

# Check connection to film_sim on the 6D
./tools/push_fs.py --status

# Convert & push a Lightroom .xmp preset directly to the 6D
./tools/push_fs.py "My_Portra_Preset.xmp" --name MYPORTRA

# Or convert offline to a .fs file for copying to ML/FILM/
./tools/xmp2fs.py "My_Portra_Preset.xmp" ML/FILM/MYPORTRA.fs

Developers · macOS / Linux

Build & install from source

git clone https://github.com/DangLamTung/XPan-Digital-Canon-6D.git
cd XPan-Digital-Canon-6D

# Clean build for Canon 6D 1.1.6
./build.sh 6D.116 clean

# Install & verify MD5 directly onto a mounted SD card
./install-sd.sh /Volumes/EOS_DIGITAL
Safety note: Magic Lantern is unofficial firmware software. Always test new builds with a charged battery, keep backups of your photos, and never pull the battery during firmware update or SD card writes.
